# Добавление группы/канала Telegram в источники

## Обзор

Фронтенд отправляет ссылку на группу/канал, бэкенд автоматически:

1. Подключает MTProto user-аккаунт к группе
2. Создаёт `LeadSource` и добавляет его в мониторинг
3. Возвращает созданный источник

---

## Эндпоинт

```
POST /api/admin/sources/mtproto/join-and-add
Authorization: Bearer <jwt_token>
Content-Type: application/json
```

### Тело запроса

| Поле                 | Тип        | Обязательное | Описание                                   |
| -------------------- | ---------- | :----------: | ------------------------------------------ |
| `url`                | `string`   |      ✅      | Ссылка на группу/канал                     |
| `directionIds`       | `string[]` |      ❌      | ID направлений для привязки                |
| `description`        | `string`   |      ❌      | Описание источника                         |
| `parsingTemplateKey` | `string`   |      ❌      | Шаблон парсинга (по умолчанию `universal`) |

### Поддерживаемые форматы `url`

| Формат                        | Пример                               |
| ----------------------------- | ------------------------------------ |
| Полная ссылка                 | `https://t.me/aachen`                |
| Username с @                  | `@aachen`                            |
| Invite-ссылка                 | `https://t.me/+AbCdEfGhIjKl`         |
| Invite-ссылка (старый формат) | `https://t.me/joinchat/AbCdEfGhIjKl` |

### Доступные шаблоны парсинга (`parsingTemplateKey`)

| Ключ           | Описание                     |
| -------------- | ---------------------------- |
| `universal`    | Универсальный (по умолчанию) |
| `standard`     | Стандартный формат           |
| `phone_only`   | Только телефоны              |
| `emoji_format` | Формат с эмодзи              |
| `table_format` | Табличный формат             |
| `crypto`       | Крипто-лиды                  |
| `realestate`   | Недвижимость                 |
| `auto`         | Авто                         |
| `none`         | Без парсинга                 |

## Коды ошибок

| Код   | Причина                                               | Что показать пользователю                                 |
| ----- | ----------------------------------------------------- | --------------------------------------------------------- |
| `400` | MTProto клиент не подключён                           | «Сервис Telegram недоступен. Обратитесь к администратору» |
| `400` | Не удалось войти в группу (закрытая, неверная ссылка) | Текст ошибки из поля `message`                            |
| `409` | Группа уже добавлена                                  | «Этот источник уже существует»                            |
| `401` | Не авторизован                                        | Редирект на логин                                         |

### Структура ошибки

```json
{
  "statusCode": 400,
  "message": "Не удалось присоединиться к чату:...",
  "error": "Bad Request"
}
```

## Рекомендуемый UX флоу

```
1. Пользователь вводит ссылку на группу
       ↓
2. Фронтенд отправляет POST /api/admin/sources/mtproto/join-and-add
       ↓
3. Показать лоадер «Подключаемся к группе...»
       ↓
4a. Успех (201) → показать карточку нового источника, тост «Источник добавлен»
4b. Ошибка (409) → «Этот источник уже добавлен»
4c. Ошибка (400) → показать message из ответа
```

### Валидация на фронтенде (до отправки)

Проверить, что ссылка соответствует одному из паттернов:

```js
const TELEGRAM_URL_RE = /^(https?:\/\/t\.me\/|@)[\w+]/i;
```

## Управление источником после добавления

| Действие                         | Метод    | Эндпоинт                                |
| -------------------------------- | -------- | --------------------------------------- |
| Включить / выключить             | `PATCH`  | `/api/admin/sources/:id/toggle`         |
| Покинуть группу и деактивировать | `POST`   | `/api/admin/sources/:id/mtproto/leave`  |
| Повторно войти в группу          | `POST`   | `/api/admin/sources/:id/mtproto/rejoin` |
| Изменить направления / описание  | `PUT`    | `/api/admin/sources/:id`                |
| Удалить источник                 | `DELETE` | `/api/admin/sources/:id`                |

---

## Проверка статуса MTProto клиента

Перед показом формы добавления можно проверить, подключён ли MTProto клиент:

```
GET /api/admin/sources/mtproto/status
```

```json
{
  "connected": true,
  "monitoredChats": ["-1001234567890", "-1009876543210"]
}
```

Если `connected: false` — отключить кнопку добавления с тултипом «Сервис Telegram недоступен».
